# 山东地名志

《山东地名志》是一张可点开的山东地名地图。以“名字”为线索，把16市136个县级政区的边界、成因与变迁收进一张可下钻的地图，配205幅AI书法字与地名云图，让史料可读可点。传播上主张轻量入口、深度留存：纯静态单页，离线可用，转发即开。创新有三：省县两级下钻与八类成因着色联动；“测一测最像你的山东地名”以互动替代说教；地名变迁做成可感知的时间线。AI工具：WorkBuddy、DeepSeek、即梦。

## 设计思路

以“名字”为唯一线索组织全站，把地名史料拆成可操作的五问：地图上它在哪、它从哪来、它有多美、它怎么变、它像谁。首页即地图，省—县两级下钻，八类成因以颜色区分，点击任一色块直接调出该县的地名档案（类型、词源、年代、出处）。视觉上以纸本、朱印、书法字建立“志书”气质，用AI生成的205幅书法字作标题与地名的点睛，使史料具备可停留的质感。

**传播理念** 轻量入口、深度留存。放弃需要安装与登录的形态，做成纯静态单页：离线可用，转发即开，一条链接即可在微信、朋友圈、公众号文中直接阅读。不追求一次性阅读量，而追求“愿意点开第二个县”的停留深度；末尾的互动测验把单向阅读转为自我投射，降低转述门槛。

## 创新点

1. 省—县两级下钻与八类成因着色联动，把分类学做成可点击的空间经验，而非静态统计表。

1) 以“测一测最像你的山东地名”替代知识灌输，让读者从旁观者变成被命名者。

1. 把地名变迁（回归／让位／合并／消逝）做成可感知的时间线，尤其呈现已消失的旧县名。

1) 书法字与地名云图将文本信息转译为视觉记忆点，强化传播识别度。

## AI 工具

* WorkBuddy：AI Agent，辅助网站搭建、交互逻辑编写与前序数据整理

- DeepSeek：文案与释文的辅助生成、校对

* 即梦：书法标题字与地名云图等视觉素材生成

## 本地预览

必须先起一个本地服务器，不能直接双击 `index.html`。
原因是浏览器对 `file://` 协议下的 `.webp` 和 canvas 有更严格的限制，用服务器访问才能完全正常。

```bash
# 任选一种
python -m http.server 8000
npx serve .
```

然后访问 <http://localhost:8000>。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（公开或私有都可以，Pages 免费版要求公开）。
2. 把本目录下的**全部文件**推到仓库根目录：

```bash
git init
git add .
git commit -m "山东地名志"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

1. 打开仓库 **Settings → Pages**，在 *Build and deployment* 里：

   * **Source** 选 `Deploy from a branch`

   * **Branch** 选 `main`，目录选 `/ (root)`

   * 点 **Save**
2. 等 1–2 分钟，访问 `https://你的用户名.github.io/你的仓库名/`。

注：**`.nojekyll`** **文件不要删。** 它让 GitHub 跳过 Jekyll 构建，保证 `assets/`、`data/` 下的文件（含带下划线或特殊字符的路径）原样发布。

## 数据说明

* 县级政区边界来自阿里云 DataV 行政区划数据，不作为行政区划依据。

* 地名由来、词源出处整理自《山东省志·地名志》及各市县地方志、民政部全国地名信息库。

* 两个「市中区」（济南、枣庄）在数据中标注为 `市中区（济南）`、`市中区（枣庄）` 以区分，页面上只显示「市中区」。
